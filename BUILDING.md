# Building from source

Back to [README.md](README.md).

This repository holds no plugin data from other mods: only `build.py`, the decisions in `records.json`, and the hashes in `inputs.sha256`. You supply the plugins in `inputs/`.

## What you need

| File in `inputs/` | Where it comes from |
|---|---|
| `Bandit War Expanded - Tamrielic Distribution.esp` | Lawless - Tamrielic Distribution Patch Update 1.0.0.0 |
| `Bandit War Expanded OWL.esp` | [Lawless - A Bandit Overhaul - Lawless Patch FOMOD](https://www.nexusmods.com/skyrimspecialedition/mods/88080) 2.1.0.0 |

`build.py` refuses a missing file or a different hash. Set `INPUTS` to use another folder.

Tools: Python 3, the .NET 10 SDK, and the `Spriggit.Yaml.Skyrim` 0.41.0 DLL. `build.py` looks for it in `SPRIGGIT_DLL`, then `<temp>/Spriggit/Translations/Spriggit.Yaml.Skyrim/0.41.0/`, then `~/.nuget/packages/spriggit.yaml.skyrim/0.41.0/`. To get it, download `https://api.nuget.org/v3-flatcontainer/spriggit.yaml.skyrim/0.41.0/spriggit.yaml.skyrim.0.41.0.nupkg` and unzip it to that NuGet folder.

## Build

```
python3 build.py          # serializes inputs/, prints the counts, writes no plugin
python3 build.py --write  # writes dist/Lawless - Tamrielic Distribution - OWL Patch.esp, then round-trips and parses it
```

Tested on macOS (arm64) only.

## When a source mod updates

`records.json` is generated by `tools/overhaul-patches` in the workspace from the live load order: run `python3 build.py --emit` there, then build here.
